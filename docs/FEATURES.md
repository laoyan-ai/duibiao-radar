# 功能、评分与局限

## 采集范围

搜索读取前N条视频，按核实账号去重，所有候选入表。N默认50、范围1—200；主页读取前M条卡片，M默认12、范围1—30。不是点赞排序搜索，也不强制半年日期筛选；主页含置顶，不是历史最高赞列表。

作者姓名、简介和样本标题用于相关度；主页卡片点赞用于点赞表现。粉丝量不计分。未成功核实主页的候选保留状态，缺失数据不补造。搜索和采集结果受页面个性化、动态加载、平台限制影响。

## 三项分数（0—100）

- **相关分**：模型分别评价简介与各视频标题。标题分取平均，简介20%＋标题80%；缺简介时仅用标题，缺标题时仅用可用简介。分数是语义判断，展开可查看理由。
- **点赞分**：取该作者已读到的有效点赞均值，用 log(1+均值) 相对本批候选最高有效均值归一到100。最高均值为0时有效零点赞得0；缺失点赞不作0。
- **综合分**：相关分70%＋点赞分30%，两项具备才生成。

点赞归一化相对本批候选；不同任务的同分不可直接横向比较。少量样本的高点赞可能被高估，界面同时展示样本数、平均/总/最高点赞和缺口。纯标题相关不等于实际内容准确，主页样本不能证明作者全部内容定位。

默认按综合分排序，点击各分数列头调整。数值显示四舍五入为整数；内部精度保留，显示同分时可能排序不同。当前流程展示所有候选，不按预设前五截断。

## 任务与数据

实时阶段、完整历史日志、暂停/停止/继续、CSV/Markdown导出。任务参数快照独立，旧任务无参数时按50/12兼容。模型配置绑定、缓存与已有评分尽量复用，避免无必要重算。

当前主流程为文本相关度和主页点赞排名。代码包含早期画面取样/分析模块，但不能将此发行版描述成自动分析全部视频的系统。不会批量下载整段视频，也不会自动发布抖音内容。
