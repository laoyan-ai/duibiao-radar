# 新手使用教程

## 1. 下载与安装

到 [Releases](https://github.com/laoyan-ai/duibiao-radar/releases) 下载 Windows 启动包。解压全部文件，放入自己有读写权限的独立目录。不要在压缩包内部双击运行。

先安装 [Node.js](https://nodejs.org/) 22 或更新版本和 [Google Chrome](https://www.google.com/chrome/)。本版正式支持 Windows；macOS/Linux 尚未验证，密钥加密功能依赖 Windows DPAPI。

双击“启动对标雷达.cmd”。首次安装依赖需要网络，随后启动本机网页。窗口保持运行，打开 http://127.0.0.1:3210 。源码包使用 start.cmd（会先构建）。源码包也可依次执行 npm ci、npm run build、npm start。

## 2. 登录自己的抖音

点击“打开浏览器 / 登录抖音”，在独立的采集 Chrome 窗口完成登录，再点“刷新登录状态”。页面分别显示浏览器是否打开、抖音是否已确认登录；未确认不等于登录成功。登录信息只留在自己电脑，不包含在发行包里。

## 3. 设置自己的模型 API

右上角“API 设置”→选择 OpenAI / DeepSeek / 通义千问 / 豆包 / 自定义兼容接口→填写自己的 API Key→选择模型→保存→测试连接。连接通过后设置区收起，再点右上角可打开。

模型列表可以显式获取，内置选项仅作起点，不代表账号有权限。DeepSeek 可先使用列表中的可用模型；豆包可能需要填写自己的推理接入点/模型ID。自定义地址必须是公开 HTTPS 地址；只向自己信任的供应商提交 Key。切换厂商时分别配置，现有任务可能绑定原厂商与模型，续跑需保留原配置。

测试连接只验证文字请求，不代表支持图像。当前博主相关度排名使用文字评分，不需要图像能力。获取列表会发送 Key 至选定厂商；连接测试与评分可能计费。ChatGPT 订阅与模型 API 账户分别管理。

无 API 也可采集、查看候选和点赞表现；相关分、综合分需配置 API。保存后可能继续符合条件的待评分任务，请先检查任务状态。

## 4. 开始一个调研

输入“企业 AI 服务”等关键词。搜索视频上限默认50、最大200；每位主页作品上限默认12、最大30，均为正整数。初次建议用10和6验证自己的环境，再增加数量。

点“查找并排名”后，依次执行：读取搜索视频→去重并核实作者主页→读取主页卡片→评分与排序。作者数量由去重结果决定，没有固定前几名截断，全部候选都在当前调研表中显示。

主页样本按当前页面顺序读取，包含置顶；不是最高赞作品全集。数据不足、字段缺失和主页失败都会说明。参数在开始时固定，中途修改输入框只影响下一次任务。

## 5. 看结果、停止与继续

当前调研卡片显示阶段、计数、进度与完整执行记录。点相关分、点赞分、综合分列头切换排序；展开行内评分依据查看简介和标题样本、缺口。数值显示为整数，内部计算保留精度，因此显示同分仍可能有先后。

运行时用卡片内“暂停”或“停止当前任务”；已保存结果保留，已发出的模型请求仍可能计费。停止会关闭软件的采集窗口。重新启动后从历史任务中选择，按页面“继续 / 重试”恢复，不会自动重新跑全部历史。不要同时启动多个副本采集。

可从任务内导出 CSV / Markdown；导出内容也可能包含个人研究数据，分享前自行检查。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 提示没有 Node | 安装 Node.js 22+，关闭后重新打开启动窗口 |
| 安装依赖失败 | 检查能否访问 npm 官方仓库，保留报错并重试，不要发送 Key |
| 页面打不开 | 启动窗口保持运行，访问127.0.0.1:3210；确认没有端口占用 |
| 提示旧版/未知服务 | 先停止任务，在原服务窗口 Ctrl+C 停止，再重新启动；不要随意结束其他程序 |
| 抖音验证、白屏、限流 | 暂停任务，在采集窗口按提示登录或手动验证，必要时刷新并等待再继续；不绕过验证 |
| 模型404/无权限 | 获取可用模型列表，使用账号实际有权限的模型，核对厂商地址 |
| 没有相关分 | 检查 API 配置、连接测试、待评分状态及运行记录；已失败任务可继续/重试 |
| 标题/点赞缺失 | 保留缺口，不能理解成零点赞，也不能用搜索卡片冒充完整主页数据 |
| 更新版本 | 先停任务及服务，保留自己本机 data 与 .local，再更新程序；二者绝不能上传到 GitHub |

不要向 Issues 贴 API Key、浏览器资料、完整任务文件或个人隐私截图。
